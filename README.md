# Lightspeed-filter-bypass-method
Bypassing of lightspeed iOS filter.

Requirements:
1. jamf student app on iOS device to be unblocked
2. jamf parent app on seperate device (requires app download)
3. iOS device (to be unblocked)

Method: 
1. Download jamf parent app on seperate device, ensuring jamf student is on the device to be unblocked.
2. Using jamf Parent, restrict lightspeed iOS filter. This only takes place 8pm-7am maximum, but time can be adjusted.
3. Restart the device with filter during the times when the filter is restricted
4. Your restarted device now has no restrictions, but YouTube and Google are permanently blocked. Use DuckDuckGo to bypass both. At https://duckduckgo.com/settings#privacy there is an option for watching videos in DuckDuckGo itself
5. To resume normal filtering, restart device outside unblocking times.

# Disclaimer: Filter may restart at any time
